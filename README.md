# 📚 Book Library Tracker

A simple web-based Book Library Tracker that helps users manage their personal book collection, track reading status, and rate completed books.

## ✨ Features

- Add books with title and author
- Set reading status
- Mark books as Read
- Mark books as Currently Reading
- Mark books as Want to Read
- Add star ratings for completed books
- Edit existing books
- Delete books
- Filter books by reading status
- View library statistics
- Store books using LocalStorage
- Data remains saved after refreshing the page
- Responsive design

## 📖 Reading Status

The application supports three reading statuses:

- 📖 Read
- 📚 Currently Reading
- 🔖 Want to Read

## ⭐ Book Ratings

Books marked as **Read** can be given a rating from:

- ⭐
- ⭐⭐
- ⭐⭐⭐
- ⭐⭐⭐⭐
- ⭐⭐⭐⭐⭐

## 📊 Library Statistics

The application displays:

- Total Books
- Books Read
- Currently Reading
- Want to Read

## 💾 LocalStorage

LocalStorage is used to save the book collection directly in the browser.

This allows books and their information to remain available even after refreshing the webpage.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

## 🚀 How to Use

1. Enter the book title.
2. Enter the author's name.
3. Select the reading status.
4. Add a rating if the book is completed/read.
5. Click **Add Book**.
6. Use the status tabs to filter books.
7. Use **Edit** to update a book.
8. Use **Delete** to remove a book.
9. Refresh the page to verify that the books are saved.
